## How to Add More AI Agents in VS Code

VS Code supports multiple AI agents through extensions. Follow the steps below to add them:

### 1. GitHub Copilot (Recommended)
- Open VS Code and go to the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
- Search for **GitHub Copilot** and click **Install**.
- Sign in with your GitHub account when prompted.
- Once installed, GitHub Copilot Chat is also available — search for **GitHub Copilot Chat** and install it too.
- Access Copilot Chat via the chat icon in the Activity Bar or with `Ctrl+Alt+I` / `Cmd+Alt+I`.

### 2. Using Multiple AI Agents via the Chat Panel
- Open the Chat panel (`Ctrl+Alt+I` / `Cmd+Alt+I`).
- Click the **agent switcher** (the `@` icon or model selector) at the top of the chat input.
- You can switch between available agents such as `@workspace`, `@terminal`, `@vscode`, and any installed third-party agents.

### 3. Adding Third-Party AI Extensions
- Go to **Extensions** (`Ctrl+Shift+X`).
- Search for AI assistants such as:
  - **Tabnine** – AI code completion
  - **Codeium** – Free AI coding assistant
  - **Amazon Q** (formerly CodeWhisperer) – AWS AI assistant
  - **Continue** – Open-source AI coding assistant
- Install the extension of your choice and follow its setup instructions.

### 4. Installing Agent Extensions from the Marketplace
- Visit the [VS Code Marketplace](https://marketplace.visualstudio.com/vscode) and search for **"AI agent"**.
- Click **Install** on the extension page, and VS Code will open and install it automatically.

### Tips
- You can have multiple AI extensions installed at the same time.
- Each extension may require its own account or API key — check the extension's documentation.
- Manage and disable extensions anytime from the Extensions view.
